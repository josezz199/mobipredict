    Cómo se eligió el modelo

    Se entrenaron varios candidatos para cada tarea y se eligió el ganador con reglas fijadas antes de ver los resultados. La prueba usa datos que el modelo nunca vio; la pandemia mide qué tanto se degrada cuando el mundo cambia.
